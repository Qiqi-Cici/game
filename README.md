# 兜风都市 · JOYRIDE CITY

> 一座可以驾车穿行的开放城市，一次浏览器里的写实驾驶体验。

`兜风都市` 是一款基于 WebGL 的 3D 城市驾驶游戏。它以 Three.js 构建实时渲染场景，以程序化方式生成城市路网与建筑，并接入真实车辆模型、HDR 天空、PBR 材质和动态交通系统。玩家可在约 1.1 公里见方的城市中执行任务、自由驾驶、改装车辆，并体验昼夜与天气变化带来的不同驾驶氛围。

## 核心特性

### 1. 可驾驶的城市

城市由程序化路网生成，包含主干道、支路、停车位、人行道与信号灯系统。三个地标建筑——兜风塔、城市体育场与摩天轮——构成城市视觉焦点。每个路口均配备带倒计时的信号机，车流与行人会依据信号状态通行或等待。

### 2. 真实车辆与驾驶手感

提供五台可驾驶车辆：

- 法拉利 458 Italia
- 兰博基尼 Aventador LP 700-4
- 兰博基尼 Urus
- 小米 SU7 Max
- 特斯拉 Model 3

车辆具备挡位、转速、氮气加速、手刹漂移与碰撞反馈。路面抓地、转向响应与加速曲线依据车辆参数分别调校。

### 3. 动态交通生态

道路上运行 25 种车型，包含普通民用车、公共服务车辆与玩家可驾驶的名车。交通参与者遵循车道与信号灯规则，行人具备等待、穿行与避让行为，并会对近距离车辆作出反应。

### 4. 任务与经济系统

| 任务 | 目标 |
| --- | --- |
| 网约车 | 接送乘客并在时限内抵达目的地 |
| 同城快递 | 限时完成四处包裹配送 |
| 街头计时赛 | 沿城市外环竞速，争取奖牌 |
| 漂移挑战 | 60 秒内累积漂移分数 |

完成任务可获得金币与经验值。车库提供车漆、轮毂、卡钳、车窗、底盘灯等外观定制，以及发动机、刹车、轮胎、氮气瓶四项性能改装。

### 5. 视听氛围

- 白天、黄昏、夜晚三个时段，天空与光照来自真实 HDR 全景图。
- 晴雨天气动态切换，路面反光、雾效与灯光随之变化。
- 五个电台均由 Web Audio 实时合成，并支持导入本地音频。
- 画质提供低、中、高三档，帧率不足时自动降低渲染分辨率。

## 交通规则

游戏采用轻松向规则，旨在提供驾驶乐趣而非严苛模拟：

- 红灯右转允许；直行、左转违规罚款 120 金币。
- 刚变红的 0.5 秒内及黄灯期间不予处罚。
- 逆行罚款 60，剐蹭罚款 80 起，惊吓行人罚款 30，碰撞行人罚款 250。
- 连续绿灯通行、高漂移分数与高速贴近超车可获得奖励。

## 技术实现

- **渲染**：Three.js / WebGL 2，ACES 色调映射，PBR 材质，实拍 HDR 环境光。
- **场景生成**：程序化路网、街区、建筑立面与植被，结合实例化渲染控制绘制开销。
- **资源**：车辆与行人模型采用 Meshopt 压缩，纹理按使用场景分级处理。
- **逻辑**：车辆物理、信号控制、交通流、行人行为、规则判定与任务系统相互独立，便于维护。
- **存档**：基于浏览器 `localStorage`，按访问地址隔离。
- **发布**：GitHub Pages 静态托管；Web 加速版将入口代码内联、素材分离并行加载，离线版将全部资源编码进单个 HTML 文件。
